# Licenses and Provenance

This directory currently retains license texts and copyright notices in the
four component directories: `asterinas/`, `rustsbi/`, `busybox/`, and `syterkit/`.
Each component follows its own license. The hardware-oriented CC0 declaration
at the repository root does not cover this third-party firmware and software.

The retained license files come from the SyterKit / RustSBI source snapshots
used for the build, the Asterinas workspace, and the BusyBox 1.37.0 source code.
The original license texts are preserved.
