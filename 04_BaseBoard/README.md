# YuzukiCube-M Base Board

Carrier board for the YuzukiNeko module. `V1.0/` holds the design outputs:

| Directory | Contents |
| --- | --- |
| `01_SCH` | Schematic PDF |
| `02_PCB` | PCB project document (`.epro2`) |
| `03_Gerber` | Gerber fabrication archive |
| `04_3D` | PCB 3D model and the base board enclosure |
| `05_BOM` | BOM spreadsheet |
| `06_PickAndPlace` | Pick-and-place / centroid file |
| `07_Project` | Full EasyEDA project archive |

The base board enclosure is in `V1.0/04_3D/3DShell_PCB2.zip` (top and bottom STL); the bottom part is also available as `V1.0/04_3D/3DShell_3DShell_PCB2_B.stl`. This is a different file from the core board enclosure in `03_Shell_3D/`.

- Base board documentation: <https://yuzukihd.github.io/YuzukiNeko/baseboard/>
- Hardware downloads: <https://yuzukihd.github.io/YuzukiNeko/hardware/download/>
- Enclosures: <https://yuzukihd.github.io/YuzukiNeko/shell/>
