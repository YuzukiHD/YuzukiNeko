title: "Hardware downloads"
---

All hardware design files are hosted on GitHub: <https://github.com/YuzukiHD/YuzukiNeko>. Click a file name to open it on GitHub, then use the download button (or *Raw*). To get everything at once, clone the repository or use *Code → Download ZIP*.

```bash
git clone https://github.com/YuzukiHD/YuzukiNeko.git
```

:::tip
Use files of the <strong>same revision</strong> as your board. Differences are listed in [Errata and revision differences](errata.md). Directory layout: [Hardware files](files.md).
:::
