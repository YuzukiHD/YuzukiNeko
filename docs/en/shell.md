# 3D-Printed Enclosure

The repository's `03_Shell_3D/` provides an enclosure for the board. The file is [YuzukiNeko_case.3mf](https://github.com/YuzukiHD/YuzukiNeko/blob/main/03_Shell_3D/YuzukiNeko_case.3mf), adapted from dj.santos's Pico enclosure (BY-NC-SA).

## Printing Tips

- Import the `.3mf` directly into your slicer; the bottom shell has a flat base and chamfered pin tips, so it can be printed without supports.
- The enclosure has openings at the USB-C and microSD ends; do a trial fit before final assembly.
