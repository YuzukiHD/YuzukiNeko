# Pin Multiplexing (MUX)

The "multiplexed functions" in the tables below are functions the SoC **can select** on a pin. They are not functions that exist simultaneously, nor do they imply that a function is wired, enabled or has a default configuration on this board. In pinctrl/pinmux software each pin can select only one function.

## General rules

- Every GPIO can be used as a plain GPIO: **Function0 = input, Function1 = output**.
- Function11–13 are reserved; **the external interrupt EINT is Function14**.
- `F<n>` in the tables is the pinmux Function number; functions in the same row are mutually exclusive.
- In software a pin is usually selected with a `port + pin number + mux` triple, for example `ALLWINNER_PINMUX(port, num, mux)` in the Zephyr devicetree.
- This page uses the **actual SoC GPIO names**. For V1.3 board silkscreen, convert using the [errata](errata.md) first.
