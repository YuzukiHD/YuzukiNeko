# Zephyr

Zephyr support for the F101 lives in the F101 west workspace: the SoC (`sun252i_f101`), the device tree, the `yuzukineko` board, and drivers for clock/reset, pinctrl, GPIO, I2C, SPI, PWM, ADC, DMA, watchdog, display, audio, USB, SD card, G2D, video decoding, and more. This chapter explains how to build and run programs on the YuzukiNeko.

!> The Zephyr board and driver code is in the F101 workspace, not in the YuzukiNeko hardware repository. All commands below are run from the workspace root.
